# VM 이미지 저장소 준비

온프레미스 호스트에서 VM 이미지 디렉터리와 libvirt 디렉터리 풀을
준비하는 Ansible 플레이북입니다.

## 파일

- `prepare-vm-storage.yml`: 디렉터리 및 공통 libvirt 풀 준비
- `vars.example.yml`: 환경별 설정 예시

## 실행 전 확인

- 인벤토리에 `onprem` 그룹과 실행할 호스트를 준비합니다.
- `vars.example.yml`의 값은 예시입니다. 실제 실행 시 대상 호스트의
  마운트 장치를 확인하고 별도 변수로 지정해야 합니다.
- `/var/lib/libvirt`가 예상한 장치에 별도 마운트돼 있어야 합니다.
- `community.libvirt` Ansible 컬렉션과 대상 호스트의 libvirt 환경이
  필요합니다.
- 기존 풀의 이름이 같더라도 타입이나 경로가 다르면 중단합니다.
  기존 풀을 자동으로 삭제하거나 덮어쓰지 않습니다.
- 실행하면 디렉터리 권한과 풀의 실행·자동 시작 상태가 변경될 수
  있으므로 대상과 영향을 검토해야 합니다.

## 범위

이 코드는 VM 이미지용 디렉터리 풀을 다룹니다. PostgreSQL의
별도 `pg-data` 볼륨 생성이나 백업 구성은 포함하지 않습니다.

## 검증 범위

- Ansible 문법 검사 결과를 PR에 기록합니다.
- 새 호스트에서의 실제 풀 생성과 전체 재구축 시험 여부를 구분합니다.
