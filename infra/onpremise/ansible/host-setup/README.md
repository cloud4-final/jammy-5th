# KVM·libvirt 호스트 준비

온프레미스 Ubuntu 호스트에 KVM·libvirt와 VM 생성에 필요한
패키지를 설치하는 Ansible 플레이북입니다.

## 파일 구성

- `prepare-kvm.yml`: KVM·libvirt 관련 패키지 설치

## 실행 전 확인

- Ansible 인벤토리에 대상 호스트의 `onprem` 그룹이 필요합니다.
- 대상 호스트 접속과 관리자 권한을 별도로 준비해야 합니다.
- 대상 환경과 설치할 패키지를 검토한 뒤 실행해야 합니다.
- 개인 인벤토리와 접속 자격 증명은 저장소에 포함하지 않습니다.

## 검증 범위

- 임시 `onprem` 인벤토리를 사용해 Ansible 문법 검사를 진행했습니다.
- 새 호스트에서 패키지 설치 및 전체 재구축 시험은 진행하지 않았습니다.
- 스토리지 풀과 cloud image 준비는 별도 작업입니다.
